Анализ:
=======

1. Лучший результат: gamma_4 >= 0.6230 (N=5, SH=40, K=5000, 627с)
   Превышает лучшую опубликованную нижнюю оценку 0.614333 на +0.0087.

2. Влияние N (размер окна):
   - N=3: макс. ~0.606 (малый горизонт, быстрая сходимость)
   - N=4: макс. ~0.619 (хороший баланс скорость/качество)
   - N=5: макс. ~0.623 (лучший результат, но 16x дороже за итерацию;
     требует больших SH и K для сходимости)

3. Влияние MAX_SH (диапазон сдвига):
   - При N=4 (K=50000):
     SH=20: 0.6167, SH=25: 0.6176, SH=30: 0.6182,
     SH=35: 0.6185, SH=40: 0.6187
   - Убывающая отдача: +0.0009, +0.0006, +0.0003, +0.0002
   - При N=5 SH=40 даёт значительный скачок (0.6230 vs 0.6163 при SH=10)

4. Влияние K (длина строк / число итераций):
   - K должно быть достаточно большим для сходимости
   - N=4: K=50000 vs K=100000 при SH=20: 0.6167 vs 0.6168 (насыщение)
   - N=5: K=5000 при SH=40 уже даёт хороший результат

5. Для дальнейшего улучшения:
   - N=5, SH=40+, K=10000+ (часы вычислений, потенциал ~0.625+)
   - N=6 теоретически возможен, но M=4096, M²=16M — нужна
     память ~2.5 ГБ на слой сдвига, реалистично только на сервере
