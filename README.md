# Улучшенная нижняя оценка для константы Чватала–Санкоффа

**Автор:** Юкачев Дмитрий Евгеньевич
**Научный руководитель:** Копелиович С. В.
**НИУ ВШЭ — Санкт-Петербург**, Прикладная математика и информатика, 2025

## Результат

Получена новая лучшая нижняя оценка константы Чватала–Санкоффа для бинарного алфавита:

**γ₂ ≥ 0.7964**

Это превосходит предыдущий рекорд 0.7927 (Heineman et al., 2024).

## Сборка и запуск

### Основной алгоритм (DP с окнами)

```bash
g++ -Ofast -std=c++17 -mavx2 -mtune=native -funroll-loops -ffast-math src/windowed_dp.cpp -o windowed_dp
./windowed_dp
```

Параметры задаются константами в начале файла:
- `N` — размер окна (число видимых символов), по умолчанию 12
- `MAX_SH` — максимальный сдвиг между позициями в строках, по умолчанию 25
- `K` — длина строк, по умолчанию 100 000

### Монте-Карло верификация

```bash
g++ -O3 -std=c++17 src/monte_carlo.cpp -o monte_carlo
./monte_carlo -n 10000 -t 1000
```

Опции: `-n` длина строк, `-t` число испытаний, `-s` seed, `-q` тихий режим.
