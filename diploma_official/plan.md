## Глава 1. Предметная область и обзор литературы (4–6 страниц)

### 1.1. Задача о наибольшей общей подпоследовательности
- Определения: подпоследовательность, LCS, классический O(n·m) DP Вагнера–Фишера.
- Случайная модель: две i.i.d.-строки над алфавитом σ.

### 1.2. Константа Чватала–Санкоффа
- Теорема 1 (Чватал–Санкофф, 1975): субаддитивность E[L_n], существование γ_σ = lim E[L_n]/n.
- Связь с задачей Улама.
- Асимптотика: γ_σ ∼ 2/√σ при σ → ∞ (Kiwi–Loebl–Matoušek, 2005).

### 1.3. Хронология нижних оценок γ_σ (особенно γ₂)
Таблица:
| Год  | Авторы                     | γ₂ ≥    | Метод                          |
|------|----------------------------|---------|--------------------------------|
| 1975 | Chvátal, Sankoff           | 0.7615  | Жадная стратегия               |
| 1995 | Dančík, Paterson           | 0.7739  | Конечные автоматы              |
| 2003 | Lueker                     | 0.7881  | Двойственная LP-формулировка   |
| 2009 | Lueker                     | 0.788   | (обзор)                        |
| 2024 | Heineman et al. (arXiv)    | 0.79266 | Расширенные state-spaces       |
| 2025 | **Данная работа**          | **0.7964** | **Оконное DP**             |

### 1.4. Верхние оценки
- Lueker (2009): γ₂ ≤ 0.826280 (двойственный метод Данчика–Патерсона).
- Зазор ≈ 0.034.

### 1.5. Эмпирические оценки
- Monte-Carlo: γ₂ ≈ 0.811, γ₃ ≈ 0.715, γ₄ ≈ 0.653 и т.д.
- Эти значения — ориентир для верхней границы качества метода.

### 1.6. Программные инструменты
- Heineman et al. публикуют код на GitHub: https://github.com/Statistics-of-Subsequences/PaperMaterials
- Современное оборудование: однопроцессорные расчёты, AVX2/SIMD.

### Выводы по главе 1

## Глава 2. Метод оконного динамического программирования (5–7 страниц)

### 2.1. Идея стратегии с ограниченным обзором
- Игра двух алгоритмов: на каждом шаге доступны окна из следующих N символов обеих строк, плюс «сдвиг» одной из строк относительно другой.
- Действие: либо сматчить текущую пару (если символы равны — обязательно), либо сдвинуть одну из строк на 1.
- Состояние: пара масок (a, b) ∈ {0,1}^N × {0,1}^N + сдвиг sh ∈ [0, MAX_SH].

### 2.2. Формальная постановка
- Пусть строки A, B длины n + MAX_SH над алфавитом размера σ.
- Стратегия π: при состоянии (a, b, sh) выбирает действие.
- Величина E_π[LCS_partial] / (n + MAX_SH) при n → ∞ — это нижняя оценка γ_σ.

### 2.3. DP-уравнения
Состояние f[sh][a][b] — ожидаемое число «совпадений» в оптимальной игре, начиная с этого состояния. Рекурсия:

f[sh][a][b] =  E_{a₀, b₀ ∼ U(σ)} [
  if (a mod σ) == (b mod σ): 1 + f[sh][a', b']
  else: max( f[sh-1 или 0][a', b∧FULL], f[sh+1 или MAX][a∧FULL, b'] )
]

где a' = (a >> BITS) | (a₀ << (MASK_BITS - BITS)), b' аналогично.

### 2.4. Граничные условия
- При sh = 0 используется зеркальный массив m0.
- При sh = MAX_SH используется m1 (текущий слой, неподвижный сдвиг).

### 2.5. Универсализация на алфавит произвольного размера
- Кодирование символа: BITS = ⌈log₂ σ⌉ бит.
- Маска N символов: MASK_BITS = BITS · N.
- Предвычисление списка валидных масок (для σ не степени двойки).

### Выводы по главе 2
- Сформулирован метод оконного DP, единообразно работающий для любого σ.
- Состояние, переходы и граничные условия даны в явной форме, пригодной для строгого анализа и реализации.

## Глава 3. Корректность и вычислительная сложность (4–6 страниц)

### 3.1. Лемма 1 (нижняя оценка через стратегию)
**Утверждение.** Для любой допустимой стратегии π выполнено:
   lim inf_{n→∞} E_π[LCS]/n ≤ γ_σ.

То есть ожидаемая длина общей подпоследовательности, построенной любой стратегией, не превосходит γ_σ.
**Доказательство:** очевидно — конкретная стратегия даёт реализуемую общую подпоследовательность, длина которой ≤ LCS.

### 3.2. Теорема 2 (корректность DP)
**Утверждение.** Значение f[sh][a][b], вычисленное по DP-уравнениям §2.3, есть ожидаемая длина общей подпоследовательности при оптимальной игре с ограниченным окном N и максимальным сдвигом MAX_SH, начиная с состояния (a, b, sh).
**Доказательство:** индукция по числу оставшихся шагов K. База: K = 0 → f = 0. Шаг: формула DP суммирует по случайным a₀, b₀ ∈ U(σ) с весами 1/σ² и берёт max по двум допустимым действиям.

### 3.3. Теорема 3 (сходимость)
**Утверждение.** lim_{K→∞} f^{(K)}[0][0][0] / (K + MAX_SH) = γ_{σ,N,MAX_SH} ≤ γ_σ.
**Идея доказательства:** теорема Фекете о субаддитивных последовательностях + регулярность нашего DP.

### 3.4. Граница приближения
- Чем больше N и MAX_SH, тем ближе γ_{σ,N,MAX_SH} к истинному γ_σ.
- Эмпирическая монотонность: γ_{σ,N,MAX_SH} ↗ при N ↑, MAX_SH ↑.

### 3.5. Анализ сложности
- **Память:** O(MAX_SH · σ^{2N}) элементов float = 4·MAX_SH·M² байт.
  - При σ = 2, N = 12, MAX_SH = 30: 4 · 31 · (4096)² ≈ 2 ГБ.
- **Время одной итерации DP:** O(MAX_SH · σ^{2N} · σ²) = O(MAX_SH · σ^{2N+2}).
- **Полное время:** O(K · MAX_SH · σ^{2N+2}).

### 3.6. Источники погрешности
- Конечный K (обрезка по длине строки).
- Округление float (контрольный пересчёт в double даёт совпадение до 5–7 знаков).

### Выводы по главе 3
- Доказана корректность DP-уравнений.
- Доказано, что вычисляемое значение — строгая нижняя оценка γ_σ.
- Получены явные формулы для памяти и времени.

### 4.5. Финальная версия (x6 / `windowed_dp.cpp`)
- Полный код краток: 92 строки. **Ключевой фрагмент** (псевдокод):

```
для L = 1..K:
    m0 ← m[1]
    для sh = MAX_SH..0:
        m1 ← m[sh]
        для всех (ma, mb) ∈ {0,1}^N × {0,1}^N:
            sum, cnt = 0, 0
            для всех (a₀, b₀) ∈ {0,1}²:
                ma1 = ma | (a₀ << N);  mb1 = mb | (b₀ << N)
                если бит₀(ma1) == бит₀(mb1):
                    sum += 1 + m1[ma1 >> 1][mb1 >> 1]
                иначе:
                    fa = m[sh-1] либо m0   (граничный случай)
                    fb = m[sh+1] либо m1
                    sum += max(fa, fb)
                cnt += 1
            m[sh][ma][mb] = sum / cnt
```

## Приложения

### Приложение A. Список сокращений и обозначений
LCS, DP, MC, σ, N, MAX_SH, K, M, BITS, MASK_BITS, AVX2.

### Приложение B. Параметры экспериментов и логи
- Полный список запусков с командами `./windowed_dp_universal SIGMA N SH K`.
- Время и память каждого запуска.

### Приложение C. Ключевые фрагменты исходного кода
- `windowed_dp.cpp` (σ = 2, рекорд) — ~30 строк ядра DP.
- `windowed_dp_universal.cpp` — переход к произвольному σ (универсальные маски).
- `monte_carlo_universal.cpp` — независимая верификация.
- Полные исходники: GitHub TODO.

### Приложение D. Дополнительные таблицы
- Зависимость γ_{2,N,MAX_SH} от N и MAX_SH.
- Зависимость γ_{σ,N,MAX_SH} от σ при фиксированных параметрах.

## План реализации (для меня, не часть ВКР)

1. Скопировать `bachelor-thesis-template-master` → `diploma_official/thesis/`.
2. Адаптировать `main.tex` (поля шаблона, ключевые слова).
3. Переписать `parts/abstract-ru.tex`, `parts/abstract-en.tex`, `parts/terminology.tex`.
4. Переписать `parts/intro.tex` (введение по плану).
5. Заменить `parts/chapter1.tex` и `chapter2.tex` на 5 глав (`chapter1.tex` .. `chapter5.tex`), обновить `main.tex`.
6. Переписать `parts/conclusion.tex`.
7. Заполнить `parts/refs.bib` (12+ источников).
8. Приложения: `appendix-*.tex` (4 шт.).
9. Скомпилировать `pdflatex` + `biber` + `pdflatex` × 2; проверить отсутствие TODO в видимом тексте.
10. Прогнать через `chktex` / визуально на предмет «висячих» ссылок.
