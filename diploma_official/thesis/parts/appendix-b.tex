\subsection*{Опции компиляции}

Пути \texttt{src/...} ниже отсчитываются от корня клонированного git-репозитория~\cite{ourgithub}.

\begin{lstlisting}[basicstyle=\small\ttfamily,language=bash,
                   caption={Опции компиляции исходников из git-репозитория~\cite{ourgithub} (пути \texttt{src/...} отсчитываются от корня клонированного репозитория)},
                   label={lst:appb-build-commands}]
# Apple Silicon / generic build:
g++ -O3 -ffast-math -std=c++17 -funroll-loops               \
    src/windowed_dp.cpp -o windowed_dp

# x86_64 with AVX2 (record server runs):
g++ -O3 -ffast-math -std=c++17 -funroll-loops               \
    -mavx2 -mbmi -mbmi2                                     \
    src/windowed_dp.cpp -o windowed_dp

# Universal version:
g++ -O3 -ffast-math -std=c++17 -funroll-loops -mavx2        \
    src/windowed_dp_universal.cpp -o windowed_dp_universal

# Monte-Carlo verifier:
g++ -O2 -std=c++17                                          \
    src/monte_carlo_universal.cpp -o monte_carlo_universal
\end{lstlisting}
