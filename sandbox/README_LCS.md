# Monte Carlo LCS для случайных бинарных строк

## Описание

Набор программ для вычисления ожидаемой длины LCS (Longest Common Subsequence) двух случайных бинарных строк методом Монте-Карло.

## Файлы

### 1. `monte_carlo_lcs.cpp`
Базовая версия программы с фиксированными параметрами:
- Длина строк: 10,000
- Количество испытаний: 1,000

**Компиляция и запуск:**
```bash
g++ -O3 -std=c++17 monte_carlo_lcs.cpp -o monte_carlo_lcs
./monte_carlo_lcs
```

### 2. `monte_carlo_lcs_advanced.cpp`
Продвинутая версия с настраиваемыми параметрами через командную строку.

**Компиляция:**
```bash
g++ -O3 -std=c++17 monte_carlo_lcs_advanced.cpp -o monte_carlo_lcs_advanced
```

**Использование:**
```bash
# Показать справку
./monte_carlo_lcs_advanced -h

# Базовый запуск (параметры по умолчанию)
./monte_carlo_lcs_advanced

# Кастомные параметры
./monte_carlo_lcs_advanced -n 5000 -t 500

# Тихий режим (без прогресса)
./monte_carlo_lcs_advanced -n 10000 -t 1000 -q

# С фиксированным seed для воспроизводимости
./monte_carlo_lcs_advanced -n 1000 -t 500 -s 42
```

**Опции:**
- `-n <число>` - Длина строк (по умолчанию: 10000)
- `-t <число>` - Количество испытаний (по умолчанию: 1000)
- `-s <число>` - Seed для генератора случайных чисел
- `-q` - Тихий режим (без прогресса)
- `-h` - Показать справку

### 3. `test_lcs_different_lengths.py`
Python скрипт для систематического тестирования на разных длинах строк.

**Запуск:**
```bash
python3 test_lcs_different_lengths.py
```

Скрипт автоматически:
1. Компилирует `monte_carlo_lcs_advanced.cpp`
2. Запускает тесты для различных длин: 50, 100, 200, 500, 1000, 2000, 5000, 10000, 20000
3. Выводит таблицу результатов
4. Анализирует тренд

## Результаты

### Экспериментальные данные

Для случайных бинарных строк (алфавит {0, 1}):

| Длина n | E[LCS] | E[LCS]/n | σ    |
|---------|--------|----------|------|
| 50      | 38.3   | 0.766    | 1.8  |
| 100     | 78.1   | 0.781    | 2.3  |
| 500     | 400.4  | 0.801    | 4.0  |
| 1000    | 804.8  | 0.805    | 5.0  |
| 5000    | 4048.4 | 0.810    | 9.7  |
| 10000   | 8104.3 | 0.810    | 10.9 |
| 20000   | 16219.5| 0.811    | 15.8 |

### Выводы

1. **Для больших n**: отношение E[LCS]/n стабилизируется около **~0.809-0.811**
2. Это означает, что LCS двух случайных бинарных строк составляет примерно **80-81%** от длины строки
3. Стандартное отклонение растет как √n

## Алгоритм

### Генерация случайных строк
- Каждый символ выбирается равновероятно из {0, 1}
- Используется Mersenne Twister (mt19937) для генерации

### Вычисление LCS
- Классическая динамическая программа O(n×m)
- Оптимизация памяти: используется O(n) вместо O(n²)
- Для двух строк длины n: время O(n²), память O(n)

### Сложность
- Время одного испытания: O(n²)
- Для n=10000 и 1000 испытаний: ~4 минуты на современном процессоре

## Примечания

- Для воспроизводимости результатов используйте опцию `-s` с фиксированным seed
- Для больших n и малого количества испытаний дисперсия может быть высокой
- Рекомендуемые соотношения:
  - n ≤ 1000: trials ≥ 1000
  - n = 5000: trials ≥ 300
  - n = 10000: trials ≥ 100
  - n ≥ 20000: trials ≥ 50

## Теоретические результаты

Для случайных строк над алфавитом размера σ асимптотически:
- E[LCS]/n → γ(σ), где γ - константа Чвата́ла-Санкоффа
- Для σ=2 (бинарный алфавит): точное теоретическое значение неизвестно
- Наши экспериментальные результаты: γ(2) ≈ 0.809-0.811
