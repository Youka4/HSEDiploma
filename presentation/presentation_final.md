## Слайд 2 — Введение в предметную область

**Заголовок:** Введение в предметную область

**Содержание (левая часть):**

> **Longest Common Subsequence (LCS)** — наибольшая общая подпоследовательность
> двух строк. Подпоследовательность получается удалением некоторых элементов
> без изменения порядка оставшихся.
>
> **Константа Чватала–Санкоффа** γ_σ (Chvátal, Sankoff, 1975):
> для двух случайных строк длины n над алфавитом размера σ
>
>     E[LCS(X, Y)] / n  →  γ_σ   при n → ∞
>
> Существование предела следует из супераддитивности и леммы Фекете.
>
> **Открытая проблема:** точное значение γ_σ неизвестно ни при каком σ
> с 1975 года.
>
> **Бинарный алфавит (σ=2) — наиболее изученный случай:**
> — нижняя оценка:  γ₂ ≥ 0.7927  (Heineman et al., 2024)
> — верхняя оценка: γ₂ ≤ 0.8263  (Lueker, 2009)
> — эмпирически (Monte-Carlo): γ₂ ≈ 0.811

**Иллюстрация справа:** LCS("ABCD", "ACBD") = "ABD", длина 3.

> **Что меняется:**
> — Уточнение «существование предела следует из супераддитивности и леммы Фекете» — на случай вопроса от жюри ссылка уже на слайде.
> — Формулировка γ_σ в общем виде (а не только γ₂), но численные границы — только для σ=2: это удерживает фокус и не размывает нарратив.
> — γ₄ по-прежнему не упоминается здесь — он появится на слайде доп. результатов.

## Слайд 5 — Предпосылки решения

**Заголовок:** Предпосылки решения

**Содержание:**

> **Идея получения нижней оценки:**
> разбиваем строки на куски, считаем E[LCS] для каждой пары кусков.
> По субаддитивности сумма E[LCS] по кускам не превосходит E[LCS] целых строк
> → среднее по куску не превосходит γ_σ, то есть даёт нижнюю оценку.
>
> Примеры (полный перебор, σ=2):
> — куски длины 1: E/n = 0.500
> — куски длины 2: E/n = 0.5625
> — куски длины 4: E/n ≈ 0.631
> — куски длины 8: E/n ≈ 0.684
>
> Полный перебор работает за O(σ^(2n) · n²) — для кусков длины ≥ 14 уже нереально.
>
> **Ключевая идея:** генерировать строки на ходу, видя только N символов вперёд.
> Любая стратегия с ограниченным обзором даёт корректную нижнюю оценку.

**Иллюстрация 1 (верх):** разбиение строк на куски, для каждого считается E[LCS].

**Иллюстрация 2 (низ):** две строки a и b с указателями, окна обзора в N символов, сдвиг между указателями.

> **Что меняется:** оставить иллюстрации с предзащиты, текст почти без изменений.
> — Только убрать «Для кусков длины 10: E/n = ...» (там было многоточие — выглядит неаккуратно).
> — Уточнить: «куски длины ≥ 14 уже нереально» (раньше было «20» — но в дипломе версия x0 ограничена n ≤ 14).
> — Заменить «k» на «σ» в обозначениях для единообразия с дипломом.

## Слайд 6 — Описание метода

**Заголовок:** Метод: оконное динамическое программирование

**Содержание (левая половина — состояние):**

> **Состояние ДП:** f_K(sh, a, b)
> — K — оставшееся число шагов
> — sh ∈ [0, MAX_SH] — текущий сдвиг между указателями
> — a, b — содержимое окон (следующие N символов каждой строки)
>
> **Возвращает:** E[длина построенной общей подпоследовательности] для оптимальной стратегии за K шагов.

**Содержание (правая половина — переходы):**

| Случай | Условие | Действие |
|---|---|---|
| Совпадение | первые символы окон совпали | взять символ в LCS, +1, сдвинуть оба окна |
| Несовпадение | sh ∈ (0, MAX_SH) | max по двум вариантам: сдвинуть a (sh → sh−1) или b (sh → sh+1) |
| Граница левая | sh = 0 | сдвинуть только b |
| Граница правая | sh = MAX_SH | сдвинуть только a |

**Иллюстрация (низ):** один переход — продвинули указатель a на 1, окно сдвинулось, в конец пришёл новый случайный символ; усредняем по обоим возможным значениям.

> **Что меняется:**
> — Старая таблица переходов с пятью строками заменена на более чёткие 4 случая (как в §2.3–2.4 диплома). Принципиальный момент: при совпадении символов стратегия **обязана** взять символ — это важно, не было явно на старом слайде.
> — Подпись «Сложность: Время O(K · MAX_SH · 2^(2N)), Память O(MAX_SH · 2^(2N))» — переносим на следующий слайд (там она уместнее), а здесь убираем чтобы не перегружать.
> — Иллюстрации с предзащиты сохраняем.
